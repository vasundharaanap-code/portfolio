# Personal Portfolio Website

A responsive portfolio website for fresher job applications, built with HTML, CSS and JavaScript. Sections: About, Education, Skills, Projects, Internships/Certifications and Contact. Includes dark/light mode and a resume download button.

## Files
- `index.html` – page content
- `style.css` – design
- `script.js` – dark mode and footer year

## How to customise
0. Put your resume in this folder and name it `resume.pdf` (the Download resume button uses it).
1. Open `index.html` and replace **Your Name**, the about text, projects and contact links.
2. Change colours at the top of `style.css` (the `--accent` variable).

## Run locally
Double-click `index.html` to open it in your browser.

## Live on GitHub Pages
Repository → **Settings** → **Pages** → Source: `main` branch, `/ (root)` → **Save**.
Your site will be at `https://your-username.github.io/repo-name/`.
